How it works

Capture

Windows Graphics Capture reads WoW's finished frame from the desktop compositor, the same way OBS does.

Neural pass

A separate process estimates motion with NVIDIA optical flow and runs DLSS 5 Neural Rendering on the frame.

Present

The result is drawn in a click-through overlay over the game window. You play normally underneath it.

A/B in one key

Hide the overlay with a hotkey to compare against the untouched game, instantly, mid-fight.

Measured on an RTX 4080 at 1440p: 11.6 ms p50, 12.6 ms p99 capture-to-present. It changes how the game looks; it does not raise your frame rate.

Why it's shaped like this

ReShade next to Wow.exe is how WoW accounts get banned. So this tool never goes near the game process. The rules are checked against the built programs on every build, not just promised:

No third-party tool can guarantee you will never be banned. This one does not do the things people get banned for.

Hotkeys

The first three are rebindable in the app. They use plain RegisterHotKey, with no keyboard hook.

Frequently asked questions

Can I get banned for using DLSS 5 in WoW?

No third-party tool can promise that. This one never loads into Wow.exe, never places ReShade or a DLL in the WoW folder, and never reads the game's memory. It reads the finished frame from Windows, like OBS or Discord screen share.

Does DLSS 5 increase FPS in World of Warcraft?

No. DLSS 5 Neural Rendering is a filter that changes how the image looks, not Super Resolution or Frame Generation. It costs frames rather than gaining them, and the app shows you exactly where each millisecond goes.

Which graphics cards are supported?

NVIDIA GeForce RTX 40 series and RTX 50 series. Older NVIDIA cards, AMD and Intel GPUs cannot run DLSS 5.

Is it a WoW addon?

No. Addons are Lua inside the game's interface. This is a separate Windows program that sits over the game window.

Why not use ReShade with a DLSS 5 addon?

Because ReShade next to Wow.exe is what gets accounts banned. Here ReShade loads into the sidecar's own process, never the game's.
